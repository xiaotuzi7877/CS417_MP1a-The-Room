NON-NEGOTIABLE WORK RULES
=========================

1. ONE CHAT / ONE MAJOR SECTION
   A work session may complete only one numbered implementation Section below.
   Do not begin the next Section, even if there is time left.

2. READ THIS FILE FIRST
   At the beginning of every future chat, read this entire file before changing
   Unity, scripts, assets, or the scene.

3. USER CHOOSES THE SECTION
   The user should say, for example, "continue Section 3". If the user only says
   "continue", resume the single Section marked IN PROGRESS. If no Section is
   IN PROGRESS, continue the first NOT STARTED Section.

4. UPDATE STATUS
   Before implementation, change only the selected Section from NOT STARTED to
   IN PROGRESS. After all acceptance checks pass, change it to DONE and add an
   entry to the Completion Log at the bottom of this file.

5. DO NOT CLAIM PARTIAL WORK AS DONE
   If a Section is incomplete or fails validation, leave it IN PROGRESS and list
   the remaining work under that Section's Notes field.

6. COMMIT EACH COMPLETED SECTION
   Each completed Section gets one focused git commit. Commit messages start with
   lowercase letters and may be informal fragments. Do not push unless the user
   explicitly requests a push.

7. PRESERVE USER WORK
   Do not stage unrelated Unity settings, SampleScene, generated Data/tmp files,
   .DS_Store files, or unrelated prefab serialization.

8. PROTECT THE MANUALLY ADJUSTED INSTRUCTION PANEL
   Do not run:
     Tools -> Michael Manor -> Layout Entry Mission Wall
   That command can overwrite the user's manually adjusted panel placement.

9. KEEP CURRENT CORE FEATURES WORKING
   Every Section must preserve:
   - three Key Props and three Lock events
   - Silver Fang / Moonstone / Blood Sigil progression
   - 20:1 Key Prop mass range
   - orbiting celestial display
   - final exit door
   - Win Celebration and five-second Congratulations text
   - presentation shortcuts unless a Section explicitly updates them

10. END-OF-SECTION REPORT
    At the end of every implementation chat, report exactly:
    - completed Section number and title
    - what changed
    - Play Mode tests performed
    - console error count
    - commit hash and message
    - whether it was pushed
    - which Section should be done next
